# 萬友咖啡 · 台中咖啡展點單系統（純本機離線版）

一個給**店員現場代客人點單**的網頁／App。點選商品 → 即時看清單與總額 → 結帳。
**完全不需要網路**：商品、庫存、銷售都存在這台平板裡（瀏覽器的 localStorage），
收攤時按「匯出 CSV」把當天訂單打包帶走做總帳。

## 🚀 馬上使用（雙擊即可）

直接**雙擊 `index.html`**，瀏覽器就會打開，馬上能用：
切換生豆／贈品、加減數量、看合計、結帳、發放贈品都正常，資料會記在這台電腦的瀏覽器裡。

## 🧰 管理按鈕（畫面上方工具列）

| 按鈕 | 作用 |
|------|------|
| **補貨** | 跳出清單，輸入每項要「**增加**」的數量 → 確認，剩餘立刻加上去。現場補貨最快。 |
| **匯出 CSV** | 把目前所有銷售紀錄下載成一個 CSV 檔（檔名 `萬友銷售_日期.csv`）。**收攤時按這個**，之後可用 Excel／Google 試算表打開做總帳。 |
| **匯入商品** | 讀一個商品 CSV，**整批取代**目前的商品清單（換商品、改價、改品項用這個）。 |
| **開新的一天** | 收攤/隔天開賣前按一次。會**自動匯出今天的 CSV 備份** → 把「目前剩餘」當作隔天的庫存起點（**庫存沿用、不會回滿**）→ 清空今日訂單。 |

工具列左邊會即時顯示「訂單 N 筆 · 贈品 M 件 · 營收 $X」。

## ✏️ 換成你的真實商品

**方法 A：用「匯入商品」（推薦，免改程式）**
1. 打開 `試算表匯入/商品.csv`（用 Excel 或記事本），照欄位改成你的商品：
   ```
   id,cat,品名,單價,單位,庫存總量,低庫存門檻
   b1,beans,衣索比亞 耶加雪菲 G1,450,包,30,5
   g1,gift,萬友馬克杯,0,個,12,5
   ```
   - `cat` 只能填 `beans`（生豆，要賣）或 `gift`（贈品，免費，單價填 0）
   - `id` 不可重複
2. 存檔後，回網頁按「**匯入商品**」選這個檔 → 商品立刻換好。

**方法 B：改程式種子**
打開 `index.html`，改最上方的 `DEFAULT_PRODUCTS`，再按「開新的一天」重置即可。

## 🔁 展期補貨怎麼做？

**最快：按工具列的「補貨」按鈕** → 在跳出的清單，幫要補的商品輸入「要增加的數量」（例如耶加輸入 10）→ 確認，剩餘立刻 +10。可一次補多項，不填的不變。

> 原理：剩餘 = 庫存總量 − 已賣，「補貨」就是把庫存加上去，所以剩餘立刻變多。
> 也可以用「**匯入商品**」改 CSV 整批重設庫存，但臨時補一兩項用「補貨」按鈕最快。

## 🎁 贈品發放（公關／滿額贈／扭蛋）

切到「**贈品**」頁籤 → 點「**＋ 發放**」→ 選原因（公關贈送／滿額贈／扭蛋獎品）→ 進購物車（$0、帶原因標籤）→ 一起結帳。贈品不計金額，但會記錄原因並扣庫存。
匯出的 CSV 裡「類別」欄就是原因，事後可在 Excel 用樞紐分析統計各類送了多少。

> 想改原因選項：改 `index.html` 最上方的 `GIFT_REASONS` 陣列。

## 📱 做成平板 App（離線可開）— 上線到 GitHub Pages

要能「加到主畫面、離線開啟」，需要先放到 GitHub Pages（一次性、要連網），之後就能離線用：

1. 把整個資料夾上傳到一個新的 GitHub repo。
2. repo → **Settings → Pages → Branch 選 main → Save** → 拿到一個網址（https 開頭）。
3. **用平板連網**打開那個網址。
4. 瀏覽器選單 → **「加到主畫面」**（Safari：分享 → 加入主畫面；Chrome：⋮ → 安裝應用程式）。
5. 完成後，**關掉 Wi-Fi 也能**從主畫面圖示開啟、正常點單。

> 為什麼要先連一次網：離線功能靠 `sw.js`（Service Worker）把程式快取在平板裡，而它**只能在 https 網站運作**（雙擊本機檔不會啟用）。所以第一次要連網開一次把它裝起來，之後整天離線都沒問題。建議展前一天在家先做好這步。

## 💾 資料保存與注意事項（重要）

- 資料存在**這台平板的這個瀏覽器**裡（localStorage）。換平板、換瀏覽器看不到同一份。
- **不要按「清除瀏覽器資料／網站資料」**，否則銷售紀錄會被清掉。
- 養成習慣：**收攤前先按「匯出 CSV」**當備份；想保險也可中午先匯出一次。
- 「開新的一天」會**自動先匯出今天的 CSV**再清空，並把庫存沿用到隔天（不會回滿），多天展覽庫存才接得上。

## 🛠 庫存售罄行為（已內建）

- **低庫存**：剩餘 ≤「低庫存門檻」→ 卡片橘色「⚠ 剩 N」提醒。
- **售罄／送完**：剩餘扣到 0（含購物車內已加的）→ 按鈕變灰「售罄」（贈品「已送完」），擋下不能再加。
