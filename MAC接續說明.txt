萬友咖啡・台中咖啡展 點單系統 — Mac 接續說明
（複製整段貼給 Mac 上的 Claude Code 即可接手）
======================================================

【專案是什麼】
台中咖啡展攤位的現場點單 POS 系統，店員代客人點單。
純本機離線 PWA（資料存平板 localStorage，免網路），沿用萬友品牌視覺。

- POS 功能：付現/刷卡、找零計算、開發票（前段固定+後段自動+1）、匯出CSV、開新的一天（庫存沿用不回滿）、補貨、匯入商品。
- 版本：SW 快取 wy-v7、style.css v=8。

【重要架構觀念】
- 單機設計：資料各平板獨立、不互通，正式營業固定用「一台」當收銀機。
- 商品是資料、存在 localStorage：改程式重開就更新；改商品/價格則「已用過的平板」要重按「匯入商品」選 CSV 才會更新，全新平板則自動有。
- 部署方式：本機專案夾不是 git repo（當初拖拉上傳）。更新是 git clone repo 到暫存→複製檔案蓋過去→commit→push。每次改完 index/style 記得把 sw.js 的 CACHE 版本號 +1，平板才抓得到新版。
  ★ Mac 上 clone 下來的資料夾「是」正式 git repo，可直接用 git add/commit/push，比 Windows 那台順。

【可能會遇到的雷】
- Mac 的 GitHub Token 可能過期：push 被要求帳密時，代表要重新產生 PAT（clone/下載通常不用，push 才要）。
