萬友咖啡 · 點單系統

店員操作使用說明

這是一台點單收銀機：一般現場結帳不需要網路，所有資料都存在這台平板裡； 只有接收業務送來的訂購單時要連網路。從主畫面的「萬友咖啡-點單系統」圖示打開即可。

1每天開始營業前

  1. 從主畫面圖示打開 App，確認上方是綠色「本機模式」。
  2. 按右上角 開新的一天：會自動備份昨天的紀錄、把營收歸零，庫存接續昨天剩下的。
第一次使用、或要換商品時，按 匯入商品 載入商品清單（CSV 檔）。上方第一行顯示「訂單數・贈品・營收」，第二行顯示各付款方式各收多少。

2幫客人點生豆

  1. 上方選「生豆」分類。
  2. 點商品的 ＋ 加入，右邊「本筆訂單」會出現品項與金額。
  3. 數量用 － ＋ 調整；按「移除」可刪掉單項。
商品卡片會顯示剩餘數量；快沒貨會出現橘字「⚠ 剩 N」，賣完會變灰「售罄」無法再加。

3預購商品（現場客訂）

  1. 生豆分類最下面有一張 預購商品 卡，按「＋ 輸入金額」。
  2. 直接打客人的客訂金額（自訂價、不佔庫存），會成為訂單裡獨立一筆。
  3. 照一般流程結帳即可；這筆會計入營業額，方便統計。
預購是為了把「現場客訂」也算進當天營收。每筆固定 1 件，不用調數量。

4發放贈品

  1. 上方切到「贈品」分類。
  2. 點 ＋ 發放 → 跳出選單，選原因：公關贈送 / 滿額贈 / 扭蛋獎品。
  3. 贈品會進到訂單（$0，不算錢），可和生豆一起結帳；三種原因共用同一份庫存。

5結帳收銀（付款・折扣・找零・發票）

  1. 按 結帳確認，跟客人核對品項與「應收總額」。
  2. 付款方式：付現 刷卡 LINE Pay 匯款 四選一。
  3. 折扣（要折才填）：在「折扣」打要折抵的金額，應收會即時扣掉，原價劃掉顯示。
  4. 找零（付現時）：在「收現」打客人給的金額，右邊自動算找零；不夠會紅字提醒。
  5. 開發票（要開才勾）：前段固定（記住上次）、後段號碼自動 +1，可手改。
  6. 確認無誤 → 按 完成並送出。
純贈品（$0）的訂單不會出現付款、折扣、找零、發票，直接送出即可。

6訂購單結帳（櫃台：業務送來的 5KG 以上訂單）

  1. 第一次使用：按右上角 訂購單，輸入密碼登入（這台平板之後會記住）。
  2. 業務送單後，按鈕上的紅色數字會增加。點開，用客人的姓名、電話或訂單編號找到這張單，按 結帳。
  3. 核對明細與金額，選付款方式，算找零、開發票的方式跟一般結帳一樣。
  4. 收完款按 完成並送出，業務那邊會即時變成「已付款」，訂單蓋上印章。
  • 金額不對、要改品項：櫃台不能改金額，也不能折扣。按 退回業務 並填原因，業務改好會重新送來。
  • 已付款後客人要改單：先退款給客人，到「已付款」分頁按 作廢，再請業務複製成新單。
訂購單收的錢會算進當天營收、付款小計和 CSV，不會扣 1KG 的庫存。付款方式選錯可到「訂單紀錄」更正；訂購單不能在訂單紀錄刪除，一律用「作廢」。

7填訂購單（業務：手機或平板）

  1. 打開訂購單網址，輸入密碼（每台裝置只要輸入一次）。
  2. 填客戶資料和商品，按 下一頁 核對明細，再按 送單到櫃台。
  3. 請客人到櫃台結帳，付款後畫面會即時變成「已付款」。
  4. 按 分享 選「儲存影像」，再到 LINE 官方帳號 App 從相簿把訂單傳給客人。
  • 還沒付款要改單：按「上一頁修改」，改完按 更新送單，編號不變，櫃台會跟著更新。
  • 被櫃台退回：到右上角「訂單列表」打開這張單，看退回原因，改好後重新送單。
  • 已作廢的單：打開後按 複製成新單，內容會帶回來，客人不用重填。
所有業務的訂單都在「訂單列表」，可以搜尋，也可以依經手人員篩選。第一次使用時，每台裝置的代號請設成不一樣（A、B、C…）。

8訂單紀錄（改付款 / 刪除）

  1. 按右上角 訂單紀錄，可看當天每一筆訂單與各付款方式小計。
  2. 點錯付款方式 → 按該筆的「改付款方式」重新選。
  3. 整筆點錯 → 按「刪除」，庫存會自動加回（無法復原，請確認再刪）。

9補貨・改價・庫存修改

  • 補貨（只會增加）：新到貨時用。輸入「要增加的數量」，按確認庫存立刻加上去。
  • 改價：現場要調整售價時用，贈品不能改價。
  • 商品卡最下面的 庫存修改（可改成任何數字）：盤點更正 / 破損 / 內部取用時用。直接把庫存改成正確數，並填調整原因，會存進紀錄供對帳。
簡單記：進貨用「補貨」，更正用「庫存修改」。

10收攤（每天結束）

  1. 按 匯出 CSV → 下載當天報表（明細＋各付款方式總計＋庫存調整紀錄，做帳用）。
  2. 按 開新的一天 → 會自動再備份一次，並把庫存接續到明天。

!重要注意事項

  • 資料存在這台平板裡，請固定用同一台當收銀機。
  • 不要清除瀏覽器資料 / 網站資料，否則紀錄會不見。
  • 養成習慣：收攤前先按「匯出 CSV」備份；中午也可先匯出一次保險。
  • 一般現場結帳沒網路也能用。訂購單要有網路才會同步，展場網路不穩時請改用行動熱點。
  • 業務斷線時送的單會先排隊（畫面顯示「待送出」），有網路會自動送出。
