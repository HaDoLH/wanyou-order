萬友咖啡 · 點單系統

店員操作使用說明

這是一台離線點單收銀機：開著就能用、不需要網路，所有資料都存在這台平板裡。 從主畫面的「萬友咖啡-點單系統」圖示打開即可。

1每天開始營業前

  1. 從主畫面圖示打開 App，確認上方是綠色「本機模式」。
  2. 按右上角 開新的一天：會自動備份昨天的紀錄、把營收歸零，庫存接續昨天剩下的。
第一次使用、或要換商品時，按 匯入商品 載入商品清單（CSV 檔）。上方第一行顯示「訂單數・贈品・營收」，第二行顯示各付款方式各收多少。

2幫客人點生豆

  1. 上方選「生豆」分類。
  2. 點商品的 ＋ 加入，右邊「本筆訂單」會出現品項與金額。
  3. 數量用 － ＋ 調整；按「移除」可刪掉單項。
商品卡片會顯示剩餘數量；快沒貨會出現橘字「⚠ 剩 N」，賣完會變灰「售罄」無法再加。

3預購商品（現場客訂）

  1. 生豆分類最下面有一張 預購商品 卡，按「＋ 輸入金額」。
  2. 直接打客人的客訂金額（自訂價、不佔庫存），會成為訂單裡獨立一筆。
  3. 照一般流程結帳即可；這筆會計入營業額，方便統計。
預購是為了把「現場客訂」也算進當天營收。每筆固定 1 件，不用調數量。

4發放贈品

  1. 上方切到「贈品」分類。
  2. 點 ＋ 發放 → 跳出選單，選原因：公關贈送 / 滿額贈 / 扭蛋獎品。
  3. 贈品會進到訂單（$0，不算錢），可和生豆一起結帳；三種原因共用同一份庫存。

5結帳收銀（付款・折扣・找零・發票）

  1. 按 結帳確認，跟客人核對品項與「應收總額」。
  2. 付款方式：付現 刷卡 LINE Pay 匯款 四選一。
  3. 折扣（要折才填）：在「折扣」打要折抵的金額，應收會即時扣掉，原價劃掉顯示。
  4. 找零（付現時）：在「收現」打客人給的金額，右邊自動算找零；不夠會紅字提醒。
  5. 開發票（要開才勾）：前段固定（記住上次）、後段號碼自動 +1，可手改。
  6. 確認無誤 → 按 完成並送出。
純贈品（$0）的訂單不會出現付款、折扣、找零、發票，直接送出即可。

6訂單紀錄（改付款 / 刪除）

  1. 按右上角 訂單紀錄，可看當天每一筆訂單與各付款方式小計。
  2. 點錯付款方式 → 按該筆的「改付款方式」重新選。
  3. 整筆點錯 → 按「刪除」，庫存會自動加回（無法復原，請確認再刪）。

7補貨 ＆ 庫存修改

  • 補貨（只會增加）：新到貨時用。輸入「要增加的數量」，按確認庫存立刻加上去。
  • 商品卡最下面的 庫存修改（可改成任何數字）：盤點更正 / 破損 / 內部取用時用。直接把庫存改成正確數，並填調整原因，會存進紀錄供對帳。
簡單記：進貨用「補貨」，更正用「庫存修改」。

8收攤（每天結束）

  1. 按 匯出 CSV → 下載當天報表（明細＋各付款方式總計＋庫存調整紀錄，做帳用）。
  2. 按 開新的一天 → 會自動再備份一次，並把庫存接續到明天。

!重要注意事項

  • 資料存在這台平板裡，請固定用同一台當收銀機。
  • 不要清除瀏覽器資料 / 網站資料，否則紀錄會不見。
  • 養成習慣：收攤前先按「匯出 CSV」備份；中午也可先匯出一次保險。
  • 沒網路也能正常使用，不用擔心展場 Wi-Fi 不穩。
